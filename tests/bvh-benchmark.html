BVH traversal experiments

Runs automatically on this browser's WebGPU adapter. Fixed rays, nearest accepted hit, separate untimed work counters, repeated interleaved GPU timestamps. Software-adapter results apply only to that adapter.

URL options: rays=8192, rounds=9, workloads=diagnostic,edges,villa,vegetation. Omit variants to run the 14 default experiments. Additional opt-in variants: branchless-slabs, original (known failing negative control). Add hardware=1 to reject software adapters. Use %2B for a plus sign in a URL parameter.
